OBIT Wi-Fi Auto-Auth для Windows 10 / 11
=========================================

Утилита автоматически отслеживает разлогин Wi-Fi ОБИТ (раз в ~2 часа)
и сама нажимает «Подключиться» в обход любого VPN, не отключая его.

УСТАНОВКА:
1. Распакуйте ВСЕ файлы из архива в любую папку (не запускайте прямо из ZIP).
2. Запустите двойным кликом файл Install.bat (права администратора НЕ нужны).
   Если Windows покажет синее окно «Защита компьютера» (SmartScreen),
   нажмите «Подробнее» -> «Выполнить в любом случае».
3. Возле часов в системном трее появится круглая иконка:
   - Зелёная   — интернет работает
   - Оранжевая — требуется вход в другой Wi-Fi, не отвечает VPN или нет сети
   - Красная   — требуется ручной вход (например, ввод телефона/SMS)
   - Серая     — Wi-Fi отключён или идёт проверка

МЕНЮ (правый клик по иконке в трее):
- «Открыть страницу входа» — появляется, если нужен ручной вход
- «Проверить и войти сейчас» — принудительно проверить/войти прямо сейчас
- «Запускать автоматически» — вкл/выкл автозапуск при входе в систему
- «Показывать уведомления» — вкл/выкл всплывающие уведомления
- «Открыть журнал работы» — посмотреть журнал работы

УДАЛЕНИЕ:
Запустите Uninstall.bat.
