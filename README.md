# OBIT Wi-Fi Auto-Auth

Утилита для автоматической переавторизации в Wi-Fi **ОБИТ** (`hspot.wifi.access5.obit.ru`) на **Windows 10/11**, **macOS** и **Linux**. Когда сессия сбрасывается (обычно раз в ~2 часа), программа сама нажимает «Подключиться» в обход любого VPN — отключать VPN и открывать браузер не нужно.

---

## Как пользоваться

Готовые архивы для всех систем публикуются на странице **Releases** этого репозитория (достаточно скачать файл для своей системы — ничего компилировать вручную не нужно).

### Windows 10 / 11

1. Скачайте `OBIT-AutoAuth-Windows.zip` и распакуйте все файлы в любую папку *(не запускайте прямо из ZIP)*.
2. Запустите двойным кликом **`Install.bat`** *(права администратора не требуются; если Windows покажет синее окно «Защита компьютера», нажмите «Подробнее» → «Выполнить в любом случае»)*.
3. Возле часов в системном трее появится круглая иконка:
   - **Зелёная** — интернет работает.
   - **Оранжевая** — требуется вход в другой Wi-Fi, не отвечает VPN или нет доступа в интернет.
   - **Красная** — требуется вход вручную (например, ввод номера телефона / SMS).
   - **Серая** — Wi-Fi отключён или идёт проверка.

**Меню (одинаковое на Windows и Linux, правый клик по иконке в трее):**
- **Открыть страницу входа** — появляется автоматически, если требуется ручной вход.
- **Проверить и войти сейчас** — принудительно запустить проверку и вход.
- **Запускать автоматически** — включить или отключить автозапуск при входе в систему.
- **Показывать уведомления** — включить или отключить всплывающие уведомления.
- **Открыть журнал работы** — посмотреть журнал работы.
- **Выход** — остановить автозащиту и закрыть значок.

**Удаление:** запустите **`Uninstall.bat`**.

> Чтобы собрать архив `dist/OBIT-AutoAuth-Windows.zip` из исходников, выполните:
> ```bash
> make build-windows
> ```

---

### macOS

1. Скачайте `OBIT-AutoAuth-macOS.zip` и распакуйте его двойным кликом.
2. Запустите двойным кликом **`Install.command`** *(права администратора не нужны; если macOS заблокирует запуск: на macOS 13–14 нажмите правой кнопкой → «Открыть», на macOS 15+ откройте «Системные настройки» → «Конфиденциальность и безопасность» → «Открыть всё равно»)*.
3. В строке меню (вверху справа) появится круглая иконка с тем же набором статусов и меню, что и на Windows и Linux.

**Удаление:** запустите **`Uninstall.command`**.

> Чтобы собрать `dist/OBIT-AutoAuth-macOS.zip` из исходников на Mac, выполните:
> ```bash
> make build-macos
> ```

---

### Linux

1. Распакуйте архив `OBIT-AutoAuth-Linux.tar.gz` и запустите установщик *(скрипт сам запросит `sudo`)*:
   ```bash
   ./install.sh
   ```
   *(Или прямо из репозитория: `make install-linux`.)*

После установки сервис работает автоматически в фоне, а в трее появляется иконка с тем же меню. Основные команды:
- `obit-auth status` — проверить состояние сервиса и сети.
- `obit-auth now` — принудительно выполнить проверку и авторизацию сейчас.
- `obit-auth logs` — посмотреть логи в реальном времени.
- `obit-auth restart` — перезапустить сервис.

**Удаление:**
```bash
./uninstall.sh
```

> Чтобы собрать архив `dist/OBIT-AutoAuth-Linux.tar.gz` из исходников, выполните:
> ```bash
> make build-linux
> ```

## Как это работает

1. **Лёгкая проверка (Fast-Path):** каждые 15 секунд проверяется доступность сети (`generate_204`). Пока интернет и VPN работают штатно, никаких дополнительных действий и правил не применяется.
2. **Обход VPN при разлогине:** если проверка не проходит, запрос авторизации направляется напрямую через физический Wi-Fi адаптер и его DHCP DNS:
   - **Windows 10/11:** Winsock `IP_UNICAST_IF (31)` + `Bind(wifiIp)` + прямой UDP DNS-запрос к DHCP DNS Wi-Fi (без прав администратора).
   - **macOS:** `Network.framework` (`NWParameters.requiredInterface`) + `SCDynamicStore` (DHCP DNS Wi-Fi) + прямой UDP DNS-запрос (без прав администратора).
   - **Linux:** `ip rule` (`priority 10`, `uidrange` для изолированного `_obitauth`) + таблица маршрутизации `1337` + прямой UDP DNS-запрос к DHCP DNS Wi-Fi.
3. **Авторизация ОБИТ:** выполняется цепочка `stage1 → ajx_check → stage3` (+ авто-отправка форм/редиректов), проверка `204` и отправка уведомления.

## Для разработчиков

### Структура репозитория
- `linux/` — `systemd --user` сервис, `obit-net-bypass`, CLI `obit-auth`, установщик (`install.sh` / `uninstall.sh`) и тесты.
- `windows/` — Tray-приложение на C# (`.NET Framework 4.8`), установщик в 1 клик (`Install.bat` / `Uninstall.bat`) и скрипт сборки (`build.sh`).
- `macos/` — Menu bar приложение на Swift (`AppKit` + `Network.framework`), установщик в 1 клик (`Install.command` / `Uninstall.command`) и скрипт сборки (`build.sh`).
- `dist/` — готовые архивы для Windows, macOS и Linux (создаются через `make build-windows` / `make build-macos` / `make build-linux`).
- `.github/workflows/build-release.yml` — автоматическая сборка для Windows (с готовым `ObitAutoAuth.exe`), macOS (universal `arm64` + `x86_64`) и Linux; при пуше тега `v*` (например, `v1.0.0`) автоматически создаётся GitHub Release со всеми тремя архивами.
