OBIT Wi-Fi Auto-Auth для macOS
================================

Утилита автоматически отслеживает разлогин Wi-Fi ОБИТ (раз в ~2 часа)
и сама нажимает «Подключиться» в обход любого VPN, не отключая его.

УСТАНОВКА:
1. Распакуйте ВСЕ файлы из архива в любую папку.
2. Запустите двойным кликом файл Install.command (права администратора НЕ нужны).
   Если macOS заблокирует запуск:
   - на macOS 13–14: нажмите правой кнопкой по Install.command -> «Открыть»;
   - на macOS 15 (Sequoia) и новее: откройте «Системные настройки» ->
     «Конфиденциальность и безопасность», прокрутите вниз и нажмите
     «Открыть всё равно» рядом с Install.command.
   После установки само приложение будет запускаться автоматически без предупреждений.
3. В строке меню (вверху справа) появится круглая иконка:
   - Зелёная   — авторизация активна
   - Оранжевая — нужен вход в другой Wi-Fi, не отвечает сеть/VPN или ошибка входа
   - Красная   — требуется ручной вход (например, ввод телефона/SMS)
   - Серая     — Wi-Fi отключён или идёт проверка

МЕНЮ (клик по иконке в строке меню):
- «Открыть страницу входа» — появляется, если нужен ручной вход
- «Проверить и войти сейчас» — принудительно проверить/войти прямо сейчас
- «Запускать автоматически» — вкл/выкл автозапуск при входе в систему
- «Показывать уведомления» — вкл/выкл уведомления
- «Открыть журнал работы» — посмотреть журнал работы

УДАЛЕНИЕ:
Запустите Uninstall.command.
