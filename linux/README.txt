OBIT Wi-Fi Auto-Auth для Linux
==============================

Утилита автоматически отслеживает разлогин Wi-Fi ОБИТ (раз в ~2 часа)
и сама нажимает «Подключиться» в обход любого VPN, не отключая его.

УСТАНОВКА:
1. Распакуйте архив и откройте терминал в распакованной папке.
2. Запустите установщик от обычного пользователя (скрипт сам запросит sudo):
   ./install.sh
3. После установки в трее появится круглая иконка:
   - Зелёная   — интернет работает
   - Оранжевая — требуется вход в другой Wi-Fi, не отвечает VPN или нет сети
   - Красная   — требуется ручной вход (например, ввод телефона/SMS)
   - Серая     — Wi-Fi отключён или идёт проверка

КОМАНДЫ В ТЕРМИНАЛЕ:
- obit-auth status  — проверить состояние сервиса и сети
- obit-auth now     — принудительно проверить/войти прямо сейчас
- obit-auth logs    — посмотреть журнал работы в реальном времени
- obit-auth restart — перезапустить сервис

УДАЛЕНИЕ:
Запустите:
./uninstall.sh
