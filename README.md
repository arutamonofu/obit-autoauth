# OBIT Wi-Fi Auto-Auth

Утилита для **Windows**, **macOS** и **Linux**, которая автоматически переподключает вас к Wi-Fi **ОБИТ**, когда сессия сбрасывается (примерно каждые 2 часа). Работает в фоне поверх любого VPN — отключать его или открывать браузер не нужно.

## Установка

1. Скачайте архив для вашей системы со страницы **Releases** и распакуйте его в любую папку.
2. Запустите установщик из распакованной папки:
   - **Windows:** `Install.bat`
   - **macOS:** `Install.command`
   - **Linux:** `./install.sh`
   *(Если система попросит подтвердить запуск или пароль, разрешите выполнение.)*
3. Возле часов появится круглая иконка — программа готова к работе.

**Удаление:** запустите `Uninstall.bat` (Windows), `Uninstall.command` (macOS) или `./uninstall.sh` (Linux).

## Индикатор и меню

Иконка возле часов показывает состояние подключения:
- 🟢 **Зелёная** — интернет работает, авторизация активна.
- 🟠 **Оранжевая** — другая сеть Wi-Fi, нет интернета или ошибка входа.
- 🔴 **Красная** — нужен вход вручную (например, по номеру телефона / SMS).
- ⚪ **Серая** — Wi-Fi выключен или идёт проверка.

По правому клику на иконку доступны:
- **Открыть страницу входа** *(появляется, если нужен ручной вход)*
- **Проверить и войти сейчас** — переподключиться принудительно
- **Запускать автоматически** — автозапуск при старте системы
- **Показывать уведомления** — вкл/выкл всплывающие уведомления
- **Открыть журнал работы** — посмотреть историю работы
- **Выход** — остановить и закрыть программу

<details>
<summary>Для разработчиков</summary>

- `windows/` — приложение для трея на C# (`.NET Framework 4.8`), установщики (`Install.bat` / `Uninstall.bat`).
- `macos/` — приложение для строки меню на Swift (`AppKit` + `Network.framework`), установщики (`Install.command` / `Uninstall.command`).
- `linux/` — `systemd --user` сервис, `obit-net-bypass`, CLI `obit-auth` (`status`, `now`, `logs`, `restart`), скрипты установки и тесты.
- `dist/` — готовые архивы для релиза (`make build-windows`, `make build-macos`, `make build-linux`).
- `.github/workflows/build-release.yml` — автосборка всех платформ при пуше тега `v*`.
- `make test` — запуск тестов.

</details>
